What this isolates

Both workloads use a WeakMap keyed by the TD and source record. Synthetic CPU reproduces an expensive derived value. SVG DOM creates a wrapper, native SVG icon, label, and status only on a cache miss, with no artificial CPU loop. Coordinate-aware DOM recycling preserves that rendered state; stationary positional reuse invalidates it as rows pass through the viewport.
